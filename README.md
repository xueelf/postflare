# Postflare

Self-hosted email on Cloudflare — receive through Email Routing, send through Email Sending, store mail in D1 and R2, run everything on Workers.

> Early development. This repository currently contains the project scaffold only.

## Development

This project uses [Bun](https://bun.sh) for dependencies, scripts, tests, and bundling.

```bash
bun install        # install dependencies
bun test           # run tests
bun run lint       # ESLint
bun run typecheck  # TypeScript
bun run format     # Prettier
```
